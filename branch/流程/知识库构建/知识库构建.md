# 知识库构建
把本次任务所需的设计知识沉淀进 `references/`，拓扑至不可再出新领域为止。
## 动作
1. 选题：设计侧（视觉层次、栅格、色彩、排版、组件与模式）+ 人因侧（可用性、无障碍、认知负荷）+ 交付侧（设计系统治理、设计-开发协作）。
2. 抓取：`python -B scripts/knowledge_fetch.py --url <白名单页> --out tmp/downloads`
   （白名单：wikipedia / w3.org / arxiv / github / stackoverflow / *.org；须 `:grant network`）。
3. 转换：`knowledge_convert.py` 把 HTML 转 md 摘要，**只存摘要与出处，不存版权正文**。
4. 落库：`references/<领域>/<主题>.md`，每文件 ≤50 行，含来源与版权标注。
5. 拓扑判据：新主题能引出未覆盖的相邻领域 → 继续；引不出 → 收口。
## 产出
- [`references/references.md`](../../../references/references.md) 索引 + 各领域子目录。
## 兜底
- 网络不可用：降级为本地既有资料 + 向用户说明缺口，禁止编造文献内容；未联网确证条目显式标注 `[本地]`。
- 缓存文件禁止写入 skill 目录（一律落用户缓存目录 / tmp）。
