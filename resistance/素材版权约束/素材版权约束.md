# 素材版权约束

本约束规定图标、字体、图片、插画等素材的来源与授权要求。

## 规则

1. **必须**每个素材在 `assets/assets.md` 登记一行：`文件名 | 来源URL | 许可证 | 版权人`。
2. **必须**许可证在白名单（MIT / CC0 / Apache-2.0 / BSD / OFL / 公有领域 / 自研 / 明确商业授权）。
3. **必须**字体确认可嵌入用途（网页/应用内嵌授权），OFL 字体保留许可证文件。
4. **必须**校验：`python -B scripts/asset_check.py --path <design>/assets/assets.md` 违规数 = 0。
5. **禁止**抓取网络图片、竞品截图、未授权图库素材直接用于交付。
6. **禁止**「来源不明但好看」入库；无法溯源即弃用。
7. **禁止**把受版权保护的正文/大图复制进 skill 目录（知识库只存摘要与出处）。

## 违规后果

- 侵权索赔与下架风险，且无法向用户交代来源。
- 无溯源记录时替换成本极高，交付不可维护。

## 兜底

- 用户自带素材：由用户书面声明授权并记逻辑链，登记时版权人填用户方。
- 找不到合规素材：降级为自绘 SVG/系统字体，并在交付说明中标注。
