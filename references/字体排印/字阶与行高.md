# 字阶与行高（摘要）

来源：[本地]（未经联网确证）。

## 要点
- 模块化字阶：base 16px × 比例 1.2–1.334；层级 ≤5 级，级差由比例导出而非随意取值。
- 行高：正文 1.5–1.75，标题 1.1–1.3；中文正文行高下限 1.6。
- 行长 45–75 字符；段间距 ≥ 行高，使「块分离」强于「行分离」。
- 字体栈：系统栈优先；自托管字体须子集化并声明 `font-display: swap`。
- 授权：字体嵌入用途（网页/应用内嵌）须单独确认，见 [素材版权约束](../../resistance/素材版权约束/素材版权约束.md)。

## 落地
- 字阶写入 `tokens/tokens.json` 的 `font` 组，经 `design_tokens.py` 生成 CSS 变量。
