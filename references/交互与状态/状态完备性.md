## 六态清单
- **正常**：有数据的默认呈现。
- **空态**：无数据时给出解释 + 下一步动作，不留白屏。
- **加载**：骨架屏或进度指示；>1s 必须可感知，>10s 须可取消。
- **错误**：说明发生了什么、用户能做什么；禁止只报错误码。
- **无权限**：说明所需权限与申请路径。
- **部分失败**：批量操作中逐项标注结果。

## 组件状态
default / hover / active / focus-visible / disabled / loading 六态必须齐备，
缺 focus-visible 即无障碍违规（见 [无障碍约束](../../resistance/无障碍约束/无障碍约束.md)）。
