# 栅格系统与 8pt 间距（摘要）

来源：[本地]（未经联网确证）。

## 要点
- 间距用 4/8 倍数体系（4/8/12/16/24/32/48）；非体系取值须有明确理由。
- 列栅格：桌面 12 列 / 平板 8 列 / 移动 4 列；沟槽与外边距同源于令牌。
- 断点最小验证集 320 / 768 / 1280；按内容断点增删，而非按机型穷举。
- 正文可读宽度 45–75 字符/行；超宽加边距而非缩字号。

## 落地
- `layout_lint.py` 查 viewport 声明、固定大宽度、溢出截断、热区尺寸。
- `visual_regression.py` 三断点各建基线。
